# Project Infinity Product Plan

## Product Thesis

Project Infinity should teach permanent data thinking. SQL syntax is treated as the tool that connects a business story to measurable decisions.

## MVP Built Now

1. 24-week roadmap with phases and levels.
2. Weekly lesson checklist with XP.
3. SQL practice area that checks for core query patterns before revealing a solution.
4. Daily retention review and streak tracking.
5. Monthly boss battle prompts based on realistic business scenarios.
6. Badge system that rewards behavior from the PDF rules.

## Design Principles Applied

- The first screen is the working dashboard, not a landing page.
- Every week has a visible win and business translation.
- The learner attempts before seeing the solution.
- Progress is visible through levels, XP, completion, streaks, and badges.
- The app stays dependency-light so the project can start immediately.

## Suggested Next Build Order

1. Add a browser SQL engine such as SQLite compiled to WebAssembly.
2. Store lesson history in a backend or local export file.
3. Turn review prompts into spaced repetition cards.
4. Add real company case packs for the boss battles.
5. Create mentor/instructor review views.
